# videoclub-colaborativo
Aplicación de gestión de un videoclub desarrollada en Laravel por Ana Uribe Gómez y Héctor Llano Lama

## Requisitos

- PHP 8.2 o superior
- Composer
- MySQL o MariaDB
- Git

## Instalación

Ver la guía completa en [docs/instalacion.md](docs/instalacion.md).

## Configuración

Ver la guía completa en [docs/configuracion.md](docs/configuracion.md).

## Ejecución

Para arrancar el servidor de desarrollo:

    php artisan serve

Después abre http://localhost:8000 en el navegador.

## Estructura

- `app/`: lógica de la aplicación
- `resources/views/peliculas/`: vistas del listado y del formulario
- `routes/`: rutas de la aplicación
- `docs/`: documentación del proyecto
