# videoclub-colaborativo

## Descripción
Aplicación de gestión de un videoclub desarrollada en Laravel. (Un par de frases sobre qué permite hacer: listar, buscar y filtrar películas y añadir nuevas.)

## Integrantes
- Ana Uribe Gómez: listado, búsqueda y filtrado de películas.
- Héctor Llano Lama: formulario para añadir películas.

## Tecnologías utilizadas
PHP, Laravel, Blade, Git y GitHub.

## Requisitos
PHP, Composer, Git y una base de datos (MySQL o MariaDB).
